## OpenBSD support

This fork contains an experimentally tested OpenBSD 7.9 amd64 port of RStudio Server 2026.10.

See [OPENBSD.md](OPENBSD.md) for tested versions, current status, and OpenBSD-specific notes. Reproducible build and setup scripts are available in the companion repository:

https://github.com/Lars-Mehnen/rstudio-server-openbsd

This OpenBSD port is experimental and is not an officially supported Posit platform.
